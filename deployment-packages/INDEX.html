⚡ Quick Start (5 Minutes)

For experienced DevOps teams:

ssh -i key.pem ubuntu@your-instance-ip # Install dependencies curl -sL https://deb.nodesource.com/setup_18.x | sudo -E bash - sudo apt install -y nodejs mongodb-org nginx sudo npm install -g pm2 # Deploy git clone https://github.com/your-org/ilead-ams.git /opt/apps/ilead-ams cd /opt/apps/ilead-ams/backend && npm install && npm run build pm2 start npm --name "ilead-backend" -- start # Configure Nginx and restart sudo systemctl restart nginx # Access at http://your-instance-ip
