## 📋 Pre-Deployment Checklist

Before deploying to Lightsail, ensure:

- [ ] AWS Lightsail account created
- [ ] Instance size: 1GB+ RAM, 1vCPU+ (2GB/2vCPU recommended)
- [ ] Operating System: Ubuntu 20.04 LTS or newer
- [ ] SSH key pair downloaded and secured
- [ ] Security groups configured (ports 22, 80, 443)
- [ ] Domain name purchased (optional but recommended)
- [ ] SSL certificate ready (Let's Encrypt is free)
- [ ] Email SMTP credentials obtained
- [ ] Database backup strategy planned
- [ ] Git repository access configured
